# Масштаб Земли — Интерактивный планетарный тест

Современный интерактивный веб-тест из **32 простых вопросов** по **8 сферам жизни**, который на основе подтверждённых международных данных показывает, в чём вы уже опережаете миллиарды людей на планете.

## Возможности
- **32 вопроса в 8 сферах** (Знания, Финансы, Здоровье, Цифровой мир, Комфорт и безопасность, Свобода и горизонты, Люди и поддержка, Рост и энергия) — прохождение занимает ~3 минуты.
- **Просто отвечать**: один клик или клавиши `1–4`, быстрый автопереход или режим «С фактом сразу».
- **100% подтверждённые источники**: World Bank (PIP & Global Findex 2025), WHO / UNICEF JMP 2025, UNESCO UIS, ILO, ITU 2025, GSMA 2025, FAO SOFI 2025, UBS Global Wealth Report, Gallup World Poll & Global Emotions 2025, Meta–Gallup, CAF World Giving Index, Ethnologue 2025, S&P Global FinLit Survey, GitHub Octoverse 2025, Microsoft Global AI Diffusion Report 2026, *Global Environmental Change* (Gössling & Humpe).
- **Визуализация результатов**:
  - Живой 3D-фон планеты на HTML5 Canvas с параллаксом и динамической палитрой.
  - Интерактивная матрица **«Если бы на Земле жило 100 человек»**.
  - Честное разделение на **личные навыки/выбор** и **базовую опору**.
  - Интерактивный **8-осевой радар** по сферам жизни.
  - Карточки нормализации («ты не один») и конкретные точки быстрого роста.
  - Экспорт персональной карточки результата в **PNG** и копирование текстового отчёта.

## Запуск

### Способ 1 — открыть готовый файл сразу (без сервера)
Просто откройте [`dist/index.html`](./dist/index.html) двойным кликом в любом современном браузере.

### Способ 2 — режим разработки
```bash
npm install
npm run dev
```

### Сборка
```bash
npm run build        # обычная production-сборка
npm run build:single # автономный единый HTML-файл dist/index.html
```
